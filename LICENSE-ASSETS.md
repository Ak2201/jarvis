# Jarvis — name, character and artwork

The [MIT License](LICENSE) covers the **source code** of Jarvis. Jarvis is a fork of
[Coucou](https://github.com/louis-cfm/coucou) by Louis Raillé.

Coucou's name, its Mochi character, icons, sounds and media are **not** MIT-licensed and are
not part of this repository: Jarvis replaced them with its own name (**Jarvis**), its own
character name (**Juno**), and generated placeholder icons and sounds.

One thing is still inherited: **Juno is still drawn by Coucou's character code** — the same
squircle body, eyes, expressions and outfits as Mochi. That code is MIT-licensed, but the
character's design belongs to Coucou's author. Redesign Juno's look (`BotEngine.swift`,
`JunoOutfitDrawing.swift`, `windows/src/juno/`, `android/.../ui/`) before you distribute Jarvis
outside your own machines, or get written permission from Coucou's author.
